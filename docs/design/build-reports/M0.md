### 2. What I built
- **Package skeleton (11.1)**: every package has an `__init__.py`. Each placeholder module has a docstring naming its owner track (T1 to T5) and its DESIGN.md section. All 66 modules import.
- **`controller/types.py` (11.2)**: every value type in 11.2 and every type those signatures use, plus `Protocol` classes for the 11.2 interfaces.
  - `Config` normalises exactly like the simulator (checked bit for bit against `sim/world.py` on thousands of random configs).
  - `Config.changed_dims()` is the simulator's own diff.
  - `Config` also has `dist()`, `body()`, `stored()`, `as_stored()`, `hash()`, `from_body()`, `from_stored()`, `problems(spec)` and `with_*` builders.
- **A real simulator trap found while building `Config`**: the simulator re-normalises every body it receives. About 23% of normalised weight sets don't add up to exactly 1.0 in floating point, so sending a stored distribution back unchanged shifts its last digits. The simulator then reports that dim as changed, which means a 403 on auto-apply if the dim isn't allowed. The contract test reproduces this end to end.
  - The fix: `body()` sends the original raw weights, or searches for weights the simulator will normalise back to the stored values. This works for about 99.5% of cases.
  - For the rest, `as_stored()` predicts exactly what the simulator will store.
- **`controller/settings.py` (5.11 and every `[T]`)**: one field per threshold, carrying its section, derivation, and whether it is tunable or a fixed contract/grader rule. `threshold_register()` generates the 5.11 table from the code.
  - `settings_hash` covers all thresholds plus `CTL_ENGAGEMENT_MODEL` and `CTL_LLM_SUGGEST`, not connection details.
  - `CTL_T_<NAME>` env vars override any threshold and change the hash.
- **Migrations and `store/db.py` (section 3, 8.5)**:
  - Files `0001` to `0008`. The first line of each says whether it targets the shared `ctl` schema or each run schema.
  - Applied files are checksummed and a changed one is refused.
  - `one_in_flight` is the partial unique index from 6.2.
  - `call_fact` has a default partition and an idempotent `ensure_call_fact_partitions()`.
  - The `ctl_api` role can read everything and write only `hold`.
  - `db.py` has `Database` (pool, `tx()`, atomic create-and-register of a run schema, `run_candidates`, `migrate_run_schema`, `update_run`, `drop_run_schema`), `AdvisoryLock` (keyed on the normalised SIM_URL, on a dedicated connection, with `held()`), `load_migrations` and `apply_migrations`.
- **Directives (6.5)**: `controller/directives.yaml` plus a loader in `controller/world/directives.py` that returns a `DirectiveLayer`. `resolve()` gives a `ResolvedDirective` with the memo source of every value; `rows()` feeds the `directive` table. Scope layering is `*` < tenant-wide < use-case keyword < workflow id.
- **SimClient (11.2, 8.4)**:
  - `client.py` and `errors.py`, with one error class per (status, code).
  - Only idempotent GETs are retried, with backoff and jitter.
  - `advance()` and all other writes are a single attempt; a timeout raises `SimTimeout` for the caller to reconcile.
  - `stream_chunk()` streams bytes and retries only before the first byte.
  - I added `workflow(wf)`, `health()` and `wait_healthy()` beyond 11.2.
- **Dependencies**: `requirements-controller.txt` adds only `psycopg[binary,pool]>=3.2,<4`. `pyproject.toml` sets pytest to importlib mode and registers the `e2e`, `pg` and `slow` markers.
- **Test helpers for other tracks**: `tests/support/sim_process.py` and `tests/support/pg.py`, plus the session fixture `pg_dsn` in `tests/conftest.py`.
- **ADR**: `docs/decisions/0027-m0-contracts.md`.

### 5. Deviations from the design
- **Postgres port**: M0 used 55450 because 55432 was taken. The PG tests use `CTL_TEST_PG_DSN` or start their own container on a random port, never a fixed one. Migrations were tested on a docker `postgres:16`, not compose, which M1 hasn't built yet.
- **Tables added to 3.2**:
  - `flag_monitor`, so the flag CUSUM state from 7.1 survives a restart (no table held it).
  - `heartbeat`, for the 10 s row in section 2.
- **Columns and indexes added**: `drift_monitor.up_cusum`, `prompt_verdict.mode` and `gate_run`, `validation_run.sim_minute`, `patch.p0_rank` and `evidence`, `alert.sim_minute`, `loop_step.wall`, a unique index on `proposal.approval_id`, partial indexes for open intents and open alerts, an index on `audit_log.caused_by`, and CHECK constraints wherever the design lists the allowed values.
- **Orphan calls**: calls whose lead was never seen stay in `call_fact` but are left out of the cell-keyed rollups (`r_engage`, `r_pickup`), because those tables need a cell in their key.
- **Fields added to `EffectivePolicy`** (with defaults): `workflow_id`, `tenant_id`, `base_reject_rate`, `notice_scope`, `notice_inside_approver_hours`, `weekly_digest`, `dialling_window`. Also `Decision.sim_minute`.
- **`CTL_LLM_SUGGEST` defaults to on**, because 17.1 overrides 7.1 (one call per incident).
- **The `*` default cohort harm line and preferred-slot offsets** come from `settings.py`, not the YAML, so each number lives in one place.
- **The directive loader** lives in `world/directives.py`; 11.1 doesn't place it.
- **`ApprovalPublic` keeps timestamps as strings**; convert with `SimEpoch.minute()`.
- **`suggest_fixes()` returns `list[Suggestion]`** as in 11.2, so it drops `credits_remaining`.

### 6. Known gaps and risks
- About 0.5% of drifting weight sets have no exact preimage. Safety then depends on T2 comparing against `as_stored()`.
- `ParamIndex` and `Draws.cell_effects()` assume each arm's effect is a linear map from parameters to cells, on either a log or logit scale. T3 may want a different shape; that would be a contract change.
- `Config.problems()` doesn't check feature values, because those come from lead events.
- `FrozenDict` can still be mutated by calling `dict.__setitem__` directly.
- The lock key is a 32-bit `hashtext`, so two different SIM_URLs could collide in theory.
- If the connecting role lacks CREATEROLE, the role grants are skipped with a notice, and only the API would then fail to start.
- `controller/__main__.py` is a placeholder (M2).
